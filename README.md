# Munnar is waiting

Simple Vue 3 / Vite countdown site for 4 November 2026, 6:00 AM India time.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The background is included at `public/munnar.jpg`. Replace this file with your own high-resolution Munnar tea plantation photo if desired. The page is responsive and displays a welcome message when the countdown ends.
